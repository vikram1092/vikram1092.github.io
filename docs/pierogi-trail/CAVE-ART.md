# Individual cave artwork

Generated with the built-in `image_gen.imagegen` tool using the previous game cave solely as a painting-style reference. These are original stylized interpretations of documented geological features, not exact reconstructions of visitor routes. Each output is packaged as WebP quality 90 under `public/pierogi-trail/art/caves/`.

## Swap an image

The single mapping is [`src/scripts/pierogi-trail/cave-art.ts`](../../src/scripts/pierogi-trail/cave-art.ts). Each stable cave ID has its own `src`, `focus`, `terrainStart`, and descriptive `feature`. Replace the corresponding WebP below, or change only that cave's `src` to a new versioned file. No changes to physics, progress, input, or rendering logic are needed.

Use an opaque 1536 × 1024 panorama. Leave the bottom ~18% as a flat, clear stone path. `focus` is the horizontal fraction centered on screen when the cave stamp is awarded; adjust it if a new painting's main formation sits elsewhere. `terrainStart` is the vertical fraction where the clear floor begins; that strip supplies the scrolling foreground. Background and floor fade together. All twelve game images are decoded before play begins; a failed asset uses the existing tap-to-retry loading flow.

References checked November 15, 2026. Composition, lighting, scale and the horseback path are artistic adaptations for the game. The seven images differ in geometry as well as color. The earlier generic `cave-v2.webp` remains an archived style reference and is no longer loaded by the game.

Pierogi now render at **56 world pixels wide**, up from 34 (about 65% larger in both dimensions). Their visual centers stay on the existing collection arcs, and edge culling includes the larger sprite. Pickup rules remain generous.

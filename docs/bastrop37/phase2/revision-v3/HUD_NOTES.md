## Runtime handoff proposal

Continue to use existing HudView/HudActions for agreed fields. Additional gameplay-owned data is proposed, not implemented: per-ability state/cooldown/binding; optional Overdrive; equipment record/source/index; connection scope, section, per-section validations and progress; escort condition/range/interception/safety; releaseCommitted; recoveryComplete; and explicit save/load result. HUD sends acknowledgment/retry/continue/settings intentions, never derives mission progress from button presses or relay brightness.

Public state requires a committed release flag, not a full local link bar. Later chapter replay must use separate run state and cannot relock Omega in completed campaign data. Preview settings never persist or introduce audio. Pause log contains acknowledged transmissions and equipment records from the review session. Each record retains its sample identity and exact receipt text, is labeled EQUIPMENT RECORD rather than attributed to a speaker, and is deduplicated on repeated acknowledgment. Merely selecting a receipt does not log it.

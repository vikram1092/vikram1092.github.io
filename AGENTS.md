# Working preferences

## Bastrop37 delivery

- The user tests Bastrop37 on the published site, not localhost. After completing and validating authorized Bastrop37 changes, commit and push them to `master` so GitHub Pages can deploy them, unless the user explicitly requests local-only work or a different delivery method.
- Verify the GitHub Pages deployment and provide the live `/bastrop37/` URL. A local preview alone does not complete delivery for this user.
- Preserve unrelated changes, use a normal push, and do not force-push.
